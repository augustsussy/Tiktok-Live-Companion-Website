Windows SmartScreen

Why Windows shows a warning

Windows flags any app from an unrecognized publisher until enough people have run it safely, or the developer pays for a code-signing certificate. Neither of those apply to a new indie app yet — it doesn't mean the file is unsafe, just unfamiliar to Windows. Here's how to get past it:

  1. Double-click the downloaded .exe. You'll see "Windows protected your PC."
  2. Click More info — this reveals a second button that wasn't visible before.
  3. Click Run anyway to start the actual installer.
