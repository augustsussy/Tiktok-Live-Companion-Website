v0.1.1 Build & Packaging

Fixed a startup crash in the packaged app (ENOTDIR)

Once asar packing was enabled, three services were still writing settings.json, spotify_tokens.json, and app.log to a path inside the read-only app.asar archive. Moved all of them onto the shared getDataDir() helper, which now resolves to Electron's writable userData folder.

v0.0.8 TikTok Integration

Stopped old chat replaying on reconnect

TikTok resends recent chat history on every reconnect, which meant comments and commands were firing a second time after any dropped connection. Added a 5-second deduplication window keyed by comment ID.
